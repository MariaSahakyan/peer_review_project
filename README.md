# peer_review_project

We are in the process of uploading the custom code and the anonymized data used to produce the figures and tables of our project. 
Before we finalize, if needed, email ms13502@nyu.edu. 


This repository contains the custom code and anonymized data used to produce the figures and tables for our project on linguistic tone and bias in peer review.
**Manuscript**: arXiv:2507.14741

**Current Contents**

	We are progressively uploading the code and data. At this stage, the repository includes:

	Code for regression analyses

	Code for n-gram analysis

	Scripts to reproduce the main tables and figures in the manuscript

**Note:** Sentiment analysis components will be added in the next update.

**Data Availability**
The anonymized dataset used in the custom code is located in _data_ folder.
